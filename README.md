# IronGrid Metalworks — Laser Cutting Services, Weld Tables & Custom Metal Art

An animated, smooth-scrolling React + TypeScript showcase built with Vite, Tailwind CSS v4, Framer Motion, and Lenis.

## Sections

1. **01 • Laser Cutting Services** — CNC laser-cutting capabilities, interactive material & tolerance spec tabs, custom branded fire rings, and heavy-gauge fire pits.
2. **02 • Weld Tables** — Flagship 4' × 8' and 4' × 6' fixture welding tables, 3-stage underframe structural anatomy (corner plates, tubular legs, painted delivery-ready underframe), and configuration specs.
3. **03 • Custom Metal Art** — Filterable CNC-cut steel wall art gallery featuring patriotic flags, military emblems, scenic cutouts, and custom painted quote plaques.

## Tech Stack

- **Framework:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS v4 (`@tailwindcss/vite`)
- **Smooth Scroll & Motion:** Lenis + Framer Motion
- **Icons:** Lucide React + custom SVG emblem (`BrandLogo` & `favicon.svg`)
